# Hush

Hush is a basic Signal client for macOS. Main goals:

- Keyboard-friendly: you can use the app without touching your mouse.
- macOS-focused: should feel right at home for mac users.
- No webviews: everything is native and feels like it.

## Keyboard Shortcuts

### General

| Shortcut | What it does |
|---|---|
| **Cmd+K** | Open the command palette to search channels |
| **Cmd+Shift+]** | Go to next channel |
| **Cmd+Shift+[** | Go to previous channel |
| **Ctrl+J** | Go to next channel |
| **Ctrl+K** | Go to previous channel |
| **Just start typing** | Focuses the message input and starts typing |

### Command Palette

| Shortcut | What it does |
|---|---|
| **↑ / Ctrl+P** | Move up in the list |
| **↓ / Ctrl+N** | Move down in the list |
| **Enter** | Select the highlighted channel |
| **Escape / Ctrl+C** | Close the palette |

### Message Input

| Shortcut | What it does |
|---|---|
| **Enter** | Send the message |
